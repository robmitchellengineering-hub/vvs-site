What Valiant proves

The AI says done. Valiant makes done mean proven — with a human tether and a tamper-evident record of every yes.

It is the one tool that closes the whole loop — verify → prove → block → coach → record → assure — for code an AI wrote.

The fears, and what Valiant does about each

“The agent said done, and it wasn't.”

Valiant's gate is a verdict, not a claim — 0 holds · 1 broken · 2 could not check. An agent cannot report “passing” unless the exit code is 0.

“Green, but nothing actually ran.”

Valiant proves the check can fail — it sabotages the code and requires the check to catch it (mutation). A check that can't be made to fail is refused. This is the fix for the “green lie”.

“Nobody can tell me who approved this.”

Every action is recorded approved / restated / traceable, hash-chained. valiant audit prints the whole decision trail — who did what, who said yes, on what evidence.

“There's no off switch.”

The Stop hook halts the agent the moment it tries to finish red, and the control number (0/1/2) says whether it is under human authority.

“The agent hides or mis-states what it did.”

The tamper-evident pack bundles every hash and signature, so a third party can verify the artefact offline — and the agent's own account is checked against the diff, not its narration.

“Approval is just rubber-stamping.”

Risk-tiered approval: read-only actions are auto-approved, write/network/secret actions require a real human tick — so the human's attention goes where the blast radius is.

“The agent read the wrong thing into what I asked.”

Before it acts, the agent restates what it means (restated), closing the asked-vs-meant gap before the action, not after.

Use it

curl -fsSL https://vvs.morpheus.nz/install.sh | sh
valiant licence <your-token>
cd your-project && valiant setup      # one command wires the gate, hooks, MCP and self-heal

Then tell your agent once:

Before you report work as done, call valiant_gate and report its exit code:
0 holds · 1 broken · 2 could-not-check. Never say passing unless it is 0.
On failure, read the why and the fix, apply it, re-run until 0.
